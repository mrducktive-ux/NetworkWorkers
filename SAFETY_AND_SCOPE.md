# Safety, Fiction and Scope

RAILWORKERS is an independent fictional game inspired by the broad theme of railway infrastructure careers. It is not Network Rail, is not endorsed by a railway operator and is not a professional training product.

All worksite scenes, asset labels, maintenance challenges, control panels and activities are invented for gameplay. They intentionally avoid actionable instructions for real track access, signalling operation, electrical isolation, railway maintenance or incident response.

The current browser build is offline-first. It does not claim to provide online multiplayer, cloud accounts, real employee verification, Discord integration or live railway data. Those features require separate backend services, security review and explicit configuration.

The Windows 7 utility is only a compatibility diagnostic. Passing its basic checks does not certify that the browser game or a modern browser can run safely or correctly on Windows 7.
