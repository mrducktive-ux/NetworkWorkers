RAILWORKERS WINDOWS 7 COMPATIBILITY TEST

This is a small standalone desktop diagnostic utility, not the full RAILWORKERS game.
Target: 32-bit x86, .NET Framework 4.0, Windows Forms.

The EXE is generated by the GitHub Actions workflow at:
.github/workflows/windows7-test.yml

After pushing the repository, open GitHub > Actions > Build Windows 7 compatibility test.
Download the artifact named RailWorkers-Windows7-Test-x86.

Runtime prerequisite: Microsoft .NET Framework 4.0 (or a compatible later in-place runtime).
The utility checks OS details, runtime, basic GDI+ rendering, keyboard input and local file access.

IMPORTANT: Building on a modern Windows runner does not certify Windows 7 compatibility.
Run the generated EXE on a Windows 7 SP1 x86/x64 test machine or verified VM before claiming support.
This utility opens the browser version using the system default browser. Modern browser support on
Windows 7 is outside the utility's control and may be limited.
